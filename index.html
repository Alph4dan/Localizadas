☁️ Base de Datos Compartida (GitHub + Vercel)

Conecta una base de datos gratuita en la nube para que todos los móviles compartan los mismos datos, Excel subidos y cambios en tiempo real.

💾 Solo local (IndexedDB)

Crea un proyecto gratis en console.firebase.google.com → Realtime Database → Copia la URL y pega aquí.

En Vercel → Storage → Create Database → Supabase. Crea una tabla trasplante_db con columnas id (text, primary key) y payload (jsonb).

💡 Truco para Vercel: Tras guardar la URL de tu base de datos aquí, pulsa "Descargar index.html listo para GitHub/Vercel" y súbelo a tu repositorio. Así todos tus compañeros se conectarán automáticamente sin configurar nada.

⏪ Puntos de Restauración (Versiones en BD)
